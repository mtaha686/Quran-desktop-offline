## Qurran Desktop — v0.1.0 (Windows)

  .A clean, offline Quran reader for your desktop — رڈیر پاٹ کسیڈ دیجم نآرق >

  ---

  ## Download

  | File | Platform |
  |---|---|
  | `Qurran-0.1.0-Windows-Setup.exe` | Windows 10/11 (64-bit) |

  ---

  ## Installation

  1. Download `Qurran-0.1.0-Windows-Setup.exe`
  2. Run the installer and follow the prompts
  3. Launch **Qurran** from the Start Menu or Desktop shortcut

  ---

  ## Features

  - Arabic text with Urdu translation side by side
  - Full-text search across all surahs and verses
  - Bookmarks with personal notes
  - Diary — attach ayahs to custom notes and export to DOCX
  - Last-read position saved automatically
  - Fully offline — no internet required

  ---

  ## System Requirements

  - Windows 10 or later (64-bit)
  - 150 MB storage

  ---

  > Linux and macOS builds coming soon.
